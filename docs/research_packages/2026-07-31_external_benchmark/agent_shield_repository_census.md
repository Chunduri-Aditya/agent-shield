# Agent Shield public repository census

Snapshot date: 2026-07-31

## Scope and method

This census covers public GitHub repositories whose repository name normalizes exactly to `agentshield` after removing punctuation and capitalization. It unions GitHub searches for `agent-shield` and `agentshield`, includes forks, and deduplicates by full repository name. This avoids unrelated partial-name results while including `AgentShield`, `Agent-Shield`, `agent_shield`, and similar punctuation variants.

- Exact-name repositories found: **379**
- Distinct non-fork repositories: **171**
- Forks: **208**

Counts and metadata are a point-in-time snapshot. Repositories can be renamed, deleted, made private, or added after this date. Forks are listed for completeness but should not be treated as independent competitors unless they contain material divergence.
